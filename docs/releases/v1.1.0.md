# SeedVR2 Upscaler GUI v1.1.0

[简体中文](#简体中文) | [English](#english)

## 简体中文

这是项目的首个公开发行版，也是第一个使用标准 Windows 安装向导的完整安装版本。

### 这次更新

- 使用普通 Windows 安装界面，不再要求用户运行 CMD 或 PowerShell 安装脚本。
- 桌面界面重构为 PySide6/Qt Widgets，窗口拖动与缩放实时跟随，消除旧界面的明显卡顿和圆角残影。
- 应用与安装向导支持简体中文/英文，首次跟随 Windows，界面右上角可即时切换并保存选择。
- 安装位置可自由选择，并提示优先选择 SSD、预留至少 15GB 空间。
- 可选择创建桌面和开始菜单快捷方式。
- 支持 2×、4×、6×、8× 倍率和 8–16GB 显存自适应分块。
- 支持点击、按钮选择、拖放三种图片导入方式。
- 支持原图、左右滑动对比和结果预览；滚轮缩放、拖动平移。
- 修复原生文件拖放闪退与进度条圆角裁切问题。

### 安装方法

请下载并放在同一目录：

```text
SeedVR2-Setup-1.1.0.exe
SeedVR2-Setup-1.1.0-1.bin
SeedVR2-Setup-1.1.0-2.bin
SeedVR2-Setup-1.1.0-3.bin
SeedVR2-Setup-1.1.0-4.bin
```

双击 `SeedVR2-Setup-1.1.0.exe`，选择简体中文或 English 后按向导安装。四个 BIN 是安装数据分卷，不能遗漏、改名或单独移动。

### 运行要求

- Windows 10/11 x64
- NVIDIA GPU 与兼容 CUDA 13.0 的驱动
- 建议 8–16GB 显存
- 安装目录至少预留 15GB，建议使用 SSD

当前已在 RTX 4070 Ti SUPER 16GB 上完成真实推理验证。8GB、12GB 的自动分块策略已有自动测试，但尚未完成对应显卡实机验证。

### 文件校验

下载 `SHA256SUMS.txt` 后可在 PowerShell 中校验，例如：

```powershell
Get-FileHash .\SeedVR2-Setup-1.1.0.exe -Algorithm SHA256
```

安装包目前没有代码签名证书，Windows 可能显示 SmartScreen 提示。

### 重要提示

SeedVR2 是生成式放大模型，可能重绘小文字、Logo、人脸、产品细节和纹理。请保留原图并检查输出结果。

## English

This is the first public release of the project and the first complete build distributed through a standard Windows setup wizard.

### What's new

- Uses a familiar Windows setup wizard instead of requiring CMD or PowerShell installation scripts.
- Rebuilds the desktop interface with PySide6/Qt Widgets for responsive live resizing and native rendering without the old rounded-corner artifacts.
- Adds Simplified Chinese and English to both the app and installer. The app follows Windows on first launch, switches instantly from the top-right control, and remembers the choice.
- Allows users to choose the installation folder, with a reminder to prefer an SSD and reserve at least 15 GB of free space.
- Offers optional desktop and Start Menu shortcuts.
- Adds 2×, 4×, 6×, and 8× presets with VRAM-aware automatic tiling designed for 8–16 GB GPUs.
- Supports image selection through the input card, file picker, or drag and drop.
- Adds original, interactive before/after, and result views with mouse-wheel zoom and drag-to-pan controls.
- Fixes a native drag-and-drop crash and clipping at the rounded end of the progress bar.

### Installation

Download all five files below and keep them in the same folder:

```text
SeedVR2-Setup-1.1.0.exe
SeedVR2-Setup-1.1.0-1.bin
SeedVR2-Setup-1.1.0-2.bin
SeedVR2-Setup-1.1.0-3.bin
SeedVR2-Setup-1.1.0-4.bin
```

Run `SeedVR2-Setup-1.1.0.exe`, choose English or Simplified Chinese, and follow the setup wizard. The four BIN files are required installation data volumes; do not omit, rename, or move them separately.

### Requirements

- Windows 10/11 x64
- NVIDIA GPU with a driver compatible with CUDA 13.0
- 8–16 GB VRAM recommended
- At least 15 GB free in the installation folder; SSD recommended

Real inference has been validated on an RTX 4070 Ti SUPER with 16 GB of VRAM. The 8 GB and 12 GB automatic tiling profiles are covered by automated tests but have not yet been validated on matching physical GPUs.

### File verification

Download `SHA256SUMS.txt` and verify the files in PowerShell, for example:

```powershell
Get-FileHash .\SeedVR2-Setup-1.1.0.exe -Algorithm SHA256
```

The installer is currently unsigned, so Windows may display a SmartScreen warning.

### Important notice

SeedVR2 is a generative upscaler and may redraw small text, logos, faces, product details, or textures. Keep the source image and inspect the output before use.
